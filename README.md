Entrants write one sentence of at most 200 characters explaining the modern internet to someone arriving from 1800. A judge model compares the sentences two at a time and the best ranked win.

The program writes a single sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> Imagine a library where the book you seek opens on your table at once, and any reader may write in its margins.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
